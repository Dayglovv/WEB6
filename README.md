# WEB6
(Selectors, Effects, Animations)

**Student:** Ali
**Group:** SE-2530

## Description
This project is my work for Assignment #6. I learned how to use jQuery
for selecting elements, effects, DOM manipulation and animations.
Every part of the assignment is on a separate page and there is a navbar to move between them.

## Pages
| Page | Tasks |
|------|-------|
| `index.html` | Task 0 (setup), Task 1 (selectors and CSS) |
| `effects.html` | Task 2 (hide/show), Task 3 (fade), Task 4 (slide) |
| `dom.html` | Task 5 (add/remove), Task 6 (attributes), Task 7 (form) |
| `animations.html` | Task 8, Task 9, Task 10 (animate) |
| `project.html` | Task 11 - Image Gallery mini project |

## How to run
1. Clone the repository: `git clone <repo link>`
2. Open `index.html` in a browser (internet is needed for jQuery CDN).
3. Open the console (F12) on the first page to see `jQuery is ready!`.

## Deploy (GitHub Pages)
Settings -> Pages -> Branch `main` / root -> Save.
Link: https://github.com/Dayglovv/WEB6
